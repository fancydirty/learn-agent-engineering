# マルチエージェントコラボレーション

このコースは、タスクを複数のエージェントに分割すべき時期と、その方法について学びます。orchestrator-worker アーキテクチャ、サブエージェントが単独で理解できる委任プロンプトの書き方、各一般的なコラボレーションパターン（パイプライン、レビュー、投票）が適合する状況、そしてマルチエージェントシステム特有の失敗モード――「完了した」と主張するサブエージェントを鵜呑みにはできず、自分でチェックする必要がある――を学びます。このシリーズの最初の 5 つのコースを終え、基本的なプロンプトを書くことができ、ツール呼び出しプロトコルを理解しているが、マルチエージェントコラボレーションを体系的に学習していない開発者向けです。マルチエージェントフレームワークのソースコード、分散システムからのコンセンサスアルゴリズム、汎用オーケストレーションプラットフォームをゼロから構築する方法はカバーしません。レッスン6 では Claude API を使用して実行可能な 2 エージェント（生産者-レビュアー）パイプラインをハンズオン演習として作成しますが、目標は本番レベルのフレームワークを出荷することではなく、コラボレーションパターン自体を理解することです。

## 学習目標

- タスクを複数のエージェントに分割する価値があるかどうかを判断し、調整オーバーヘッドが利益を上回るケースを認識する
- orchestrator-subagent アーキテクチャにおけるコンテキスト分離の価値と、サブエージェントが結論のみを返すべき理由を説明する
- 明確なスコープと出力フォーマット要件を持つ、サブエージェント向けの自己完結型委任プロンプトを書く
- パイプライン、生産者-レビュアー、マルチパースペクティブ投票パターンを区別し、それぞれが適合する場所を判断する
- マルチエージェントコラボレーションにおける典型的な失敗――検証不可能な「完了」、重複作業、矛盾する結果――を認識し、対応方法を知る
- Claude API を使用して実行可能な生産者-レビュアー 2 エージェントパイプラインを書く

## 前提知識

- このシリーズの最初の 5 つのコースを終え、基本的なプロンプトを書くことができ、ツール呼び出しプロトコルを理解し、エージェントメモリと状態について知っており、基本的な JavaScript を読むことができる
- Node.js 環境があり、ターミナルでスクリプトを実行できる
- 動作する Claude API キーがある（レッスン6 のハンズオン演習に必要）

## 想定学習時間

約 4〜5 時間（各レッスンのハンズオン演習を含む）。
