# 에이전트 하네스 기초: 루프와 통제

이 코스는 에이전트의 **하네스** - 모델 바깥에서 에이전트를 실제로 돌게 만드는 통제 코드 계층 - 를 다룹니다. 하네스는 '모델 → 툴 실행 → 결과 되돌리기 → 다시 묻기' 루프를 굴리고, 그 루프가 언제 멈출지 정하고, 폭주할 때 붙잡고, 도중에 사람이 끼어들어 방향을 바꿀 수 있게 합니다. 코스는 단일 에이전트의 실행 루프에 초점을 맞추며, 마지막에는 정지 조건, 예산 상한, 공회전 감지, 사람 승인 밸브를 갖춘 최소 하네스를 직접 손으로 짜게 됩니다. 이 시리즈의 앞 여섯 개 코스를 마친 독자를 위한 코스입니다 - 한 번의 툴 호출 왕복(`stop_reason: "tool_use"` / `tool_result`), 에이전트 메모리와 컨텍스트 윈도우, 그리고 멀티 에이전트 분업의 기초를 이해하고 있어야 합니다. 이 코스는 특정 프레임워크의 API 튜토리얼이 아니며(Claude Agent SDK나 LangChain 세부 사항 없음), 멀티 에이전트 오케스트레이션(이 시리즈의 다른 코스)도, 평가와 회귀(검증 코스로 미룸)도 다루지 않습니다. 초점은 한 계층, 곧 루프 자체를 어떻게 통제 아래 두는가입니다.

## 학습 목표

이 코스를 마치면 다음을 할 수 있습니다:
- 하네스와 모델 사이에 선을 긋고, 같은 모델이라도 하네스가 다르면 왜 결과가 크게 달라질 수 있는지 설명하기
- 에이전트를 굴리는 코어 루프를 손으로 짜고, `stop_reason`이 루프를 계속할지 멈출지 어떻게 정하는지 설명하기
- 모델이 '다 했다'고 말하는 데 기대는 대신, 에이전트를 위한 명시적 정지 조건 집합을 설계하기
- 폭주 모드 - 데드 루프, 공회전, 예산 소진, 누적 오류 - 를 알아보고 각각에 폴백을 달기
- 루프의 어디에 사람 체크포인트가 들어가야 할지 판단해, 되돌릴 수 없는 작업을 자동 실행 바깥에 두기
- 제로에서, 정지 조건·최대 턴 상한·예산 상한·공회전 감지·승인 밸브를 갖춘 최소 하네스 만들기

## 사전 지식

- 이 시리즈의 앞 여섯 개 코스를 마쳤거나 그에 준하는 지식이 있다
- 한 번의 완전한 툴 호출 왕복을 이해한다: 모델이 `stop_reason: "tool_use"`를 반환하고, 호스트가 툴을 실행하며, `tool_result`가 다시 대화에 이어 붙는다
- 컨텍스트 윈도우가 유한한 자원이고 히스토리이 계속 쌓인다는 것을 안다(이 시리즈의 코스 5 '에이전트 메모리와 상태')
- 기본적인 JavaScript / Node.js 코드를 읽을 수 있다(레슨 6에서 따라 쓰게 됨)
- 머신러닝이나 모델 학습 배경 지식은 필요 없다
