# Claude Code Skills: 나만의 AI 워크플로 만들기

이 코스에서는 Claude Code Skills를 만드는 방법을 배웁니다. 반복되는 워크플로를 재사용 가능한 지시문으로 패키징해서, 프로젝트가 필요로 하는 방식대로 Claude가 움직이게 합니다. 이미 Claude Code를 쓰고 있고 그 동작을 커스터마이즈하고 싶은 개발자를 위한 코스입니다.

## 코스 구성

6. [고급 패턴: 스킬을 더 강력하게 만들기](06-advanced-patterns.md)

## 학습 목표

이 코스를 마치면 다음을 할 수 있습니다:
- Skill의 동작 원리와 적용 지점 이해하기
- 구조가 잘 잡힌 SKILL.md 파일을 스스로 작성하기
- 자신의 Skill을 테스트하고 디버깅하기
- 실제 프로젝트를 위한 프로덕션 수준의 커스텀 워크플로 만들기
- Skill을 신뢰할 수 있고 유지보수하기 좋게 지키는 모범 사례 적용하기

## 사전 지식

- Claude Code의 기본 기능을 써 본 적이 있다
- Markdown 기본 문법을 안다
- 터미널에서 간단한 명령을 실행할 수 있다
- 프로그래밍 언어를 하나라도 다뤄 본 경험이 있다

## 예상 학습 시간

실습 연습을 포함해 약 3~4시간.
