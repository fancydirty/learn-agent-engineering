# Claude Code Skills: 自分専用の AI ワークフローを作る

このコースでは、Claude Code Skills の作り方を学びます。繰り返し発生するワークフローを再利用可能な指示としてパッケージ化し、プロジェクトの必要に応じて Claude を動かせるようにします。すでに Claude Code を使っていて、その動きをカスタマイズしたい開発者向けです。

## コース構成

1. [Skill とは何か: なぜカスタムワークフローが必要なのか](01-what-are-skills.md)
2. [Skill の解剖: SKILL.md ファイル](02-skill-anatomy.md)
3. [ハンズオン: 最初の Skill を書く](03-first-skill.md)
4. [テストとデバッグ: Skill が期待どおり動くことを確かめる](04-testing-debugging.md)
5. [ケーススタディ: コードレビュー Skill を作る](05-code-review-skill.md)
6. [応用パターン: Skill をより強力にする](06-advanced-patterns.md)

## 学習目標

このコースを終えると、次のことができるようになります:
- Skill の仕組みと、それがどこで役立つかを理解する
- 構造の整った SKILL.md ファイルを自分で書く
- 自分の Skill をテストしデバッグする
- 実際のプロジェクト向けに、本番で使えるカスタムワークフローを作る
- Skill を信頼でき保守しやすい状態に保つベストプラクティスを適用する

## 前提知識

- Claude Code の基本機能を使ったことがある
- Markdown の基本文法を知っている
- ターミナルで簡単なコマンドを実行できる
- いずれかのプログラミング言語の経験がある

## 想定学習時間

約 3〜4 時間（ハンズオン演習を含む）。
