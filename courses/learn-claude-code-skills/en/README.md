# Claude Code Skills: Build Your Own AI Workflows

This course teaches you how to create Claude Code Skills — packaging repetitive workflows into reusable instructions so Claude works the way your project needs. It's for developers who already use Claude Code and want to customize how it works.

## Course outline

1. [What Skills Are: Why You Need Custom Workflows](01-what-are-skills.md)
2. [Anatomy of a Skill: The SKILL.md File](02-skill-anatomy.md)
3. [Hands-On: Writing Your First Skill](03-first-skill.md)
4. [Testing and Debugging: Making Sure Your Skill Behaves](04-testing-debugging.md)
5. [Case Study: Building a Code Review Skill](05-code-review-skill.md)
6. [Advanced Patterns: Making Skills More Powerful](06-advanced-patterns.md)

## Learning goals

By the end of this course you'll be able to:
- Understand how Skills work and where they apply
- Write a well-structured SKILL.md file on your own
- Test and debug your Skills
- Build production-ready custom workflows for real projects
- Apply best practices that keep Skills reliable and maintainable

## Prerequisites

- You've used Claude Code's basic features
- You know basic Markdown syntax
- You can run simple commands in a terminal
- You have experience with any programming language

## Estimated time

About 3-4 hours, including the hands-on exercises.
