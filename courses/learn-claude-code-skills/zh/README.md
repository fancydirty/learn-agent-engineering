# Claude Code Skills：打造你的专属 AI 工作流

本课程教你如何创建 Claude Code Skills，将重复性工作流打包成可复用的指令，让 Claude 按照你的特定需求工作。适合已使用过 Claude Code、想要定制工作流程的开发者。

## 课程大纲

1. [认识 Skills：为什么需要自定义工作流](01-what-are-skills.md)
2. [Skill 的解剖：SKILL.md 文件结构](02-skill-anatomy.md)
3. [动手实践：编写你的第一个 Skill](03-first-skill.md)
4. [测试与调试：确保 Skill 按预期工作](04-testing-debugging.md)
5. [实战案例：构建代码审查 Skill](05-code-review-skill.md)
6. [进阶技巧：让 Skill 更强大](06-advanced-patterns.md)

## 学习目标

完成本课程后，你将能够：
- 理解 Skills 的工作原理和应用场景
- 独立编写结构清晰的 SKILL.md 文件
- 测试和调试你的 Skills
- 为实际项目创建生产可用的自定义工作流
- 应用最佳实践让 Skills 更可靠和易维护

## 前置要求

- 已经使用过 Claude Code 的基本功能
- 熟悉 Markdown 基础语法
- 能在命令行中运行基本命令
- 有过任何编程语言的经验

## 预计学习时间

约 3-4 小时，包括动手练习
