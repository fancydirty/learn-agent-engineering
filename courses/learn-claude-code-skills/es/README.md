# Claude Code Skills: crea tus propios flujos de trabajo con IA

Este curso te enseña a crear Claude Code Skills: empaquetar flujos de trabajo repetitivos en instrucciones reutilizables para que Claude trabaje como tu proyecto necesita. Está pensado para quienes ya usan Claude Code y quieren personalizar su forma de trabajar.

## Contenido del curso

1. [Qué son las Skills: por qué necesitas flujos de trabajo propios](01-what-are-skills.md)
2. [Anatomía de una Skill: el archivo SKILL.md](02-skill-anatomy.md)
3. [Práctica: escribir tu primera Skill](03-first-skill.md)
4. [Pruebas y depuración: asegurar que tu Skill se comporte](04-testing-debugging.md)
5. [Caso práctico: construir una Skill de revisión de código](05-code-review-skill.md)
6. [Patrones avanzados: hacer que las Skills sean más potentes](06-advanced-patterns.md)

## Objetivos de aprendizaje

Al terminar este curso podrás:
- Entender cómo funcionan las Skills y dónde se aplican
- Escribir por tu cuenta un archivo SKILL.md bien estructurado
- Probar y depurar tus Skills
- Construir flujos de trabajo propios listos para producción en proyectos reales
- Aplicar buenas prácticas que mantienen las Skills fiables y mantenibles

## Requisitos previos

- Has usado las funciones básicas de Claude Code
- Conoces la sintaxis básica de Markdown
- Puedes ejecutar comandos sencillos en una terminal
- Tienes experiencia con algún lenguaje de programación

## Tiempo estimado

Unas 3-4 horas, incluidos los ejercicios prácticos.
