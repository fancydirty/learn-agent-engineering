# Claude Code Skills: crie seus próprios fluxos de trabalho com IA

Este curso ensina você a criar Claude Code Skills: empacotar fluxos de trabalho repetitivos em instruções reutilizáveis para que o Claude trabalhe do jeito que seu projeto precisa. Ele é para quem já usa o Claude Code e quer personalizar como ele funciona.

## Conteúdo do curso

1. [O que são Skills: por que você precisa de fluxos de trabalho personalizados](01-what-are-skills.md)
2. [Anatomia de uma Skill: o arquivo SKILL.md](02-skill-anatomy.md)
3. [Mão na massa: escrevendo sua primeira Skill](03-first-skill.md)
4. [Testes e depuração: garantindo que sua Skill se comporte](04-testing-debugging.md)
5. [Estudo de caso: construindo uma Skill de code review](05-code-review-skill.md)
6. [Padrões avançados: tornando as Skills mais poderosas](06-advanced-patterns.md)

## Objetivos de aprendizado

Ao final deste curso você será capaz de:
- Entender como as Skills funcionam e onde elas se aplicam
- Escrever sozinho um arquivo SKILL.md bem estruturado
- Testar e depurar suas Skills
- Construir fluxos de trabalho personalizados prontos para produção em projetos reais
- Aplicar boas práticas que mantêm as Skills confiáveis e fáceis de manter

## Pré-requisitos

- Você já usou os recursos básicos do Claude Code
- Você conhece a sintaxe básica de Markdown
- Você consegue executar comandos simples em um terminal
- Você tem experiência com alguma linguagem de programação

## Tempo estimado

Cerca de 3-4 horas, incluindo os exercícios práticos.
