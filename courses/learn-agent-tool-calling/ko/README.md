# 에이전트 도구 호출: 에이전트가 실제로 일하게 만들기

이 코스에서는 에이전트 도구 호출(tool use / function calling)의 전체 메커니즘을 따라갑니다. 도구 호출 요청과 응답 사이를 오가는 필드가 정확히 무엇인지, 흔한 다섯 가지 도구 유형(읽기, 쓰기, 실행, 검색, 외부 API 호출)의 위험 경계는 어디인지, 모델이 제대로 고르고 제대로 채우는 도구 인터페이스는 어떻게 쓰는지, 그리고 권한 등급과 프롬프트 인젝션 방어를 어떻게 실무에 적용하는지 다룹니다. 기본적인 프롬프트를 쓸 수 있고 Claude Code 같은 도구를 써 봤지만, 그 밑에 깔린 도구 호출 프로토콜은 아직 체계적으로 공부하지 않은 개발자를 위한 코스입니다. 특정 에이전트 프레임워크(LangChain, AutoGPT)는 가르치지 않고 모델 학습이나 파인튜닝도 다루지 않습니다. 초점은 사슬 그 자체, 즉 모델이 어떻게 행동을 요청하고 호스트가 그것을 어떻게 안전하게 실행하는지에 있습니다.

## 학습 목표

이 코스를 마치면 다음을 할 수 있습니다:
- 도구 호출에서 "모델은 제안만 하고 호스트가 실행한다"는 경계선을 설명하고, 그것으로 어떤 작업에 도구가 정말 필요한지 판단하기
- 병렬 호출 여러 개의 일괄 반환을 포함해, 완전한 tool_use / tool_result 왕복을 읽고 직접 쓰기
- 다섯 가지 도구 유형(읽기, 쓰기, 실행, 검색, 외부 API 호출)을 영향 반경으로 분류하고 각각이 가장 빠지기 쉬운 함정 짚어내기
- 모델이 알맞은 도구를 고르고, 파라미터를 제대로 채우고, 실패한 뒤 스스로 교정하게 하는 도구 description과 JSON Schema와 반환값 쓰기
- 도구 작업에 allow / ask / deny 등급을 매기고, 과도한 권한 부여와 치명적 3요소(lethal trifecta) 조합의 위험을 알아보기
- 실행 루프와 레지스트리와 안전장치를 갖춘 도구 호출 에이전트를 처음부터 만들기

## 사전 지식

- 기본적인 프롬프트를 쓸 수 있고 LLM과의 대화가 어떤 형태인지 안다
- Claude Code나 비슷한 AI 코딩 도구를 써 봤고, 그것이 파일을 읽고 쓰고 명령을 실행할 수 있다는 것을 안다
- 기본적인 JavaScript / Node.js 코드를 읽을 수 있다(레슨 6에서 코드를 따라가며 실습합니다)
- 머신러닝이나 모델 학습 배경 지식은 필요하지 않다
