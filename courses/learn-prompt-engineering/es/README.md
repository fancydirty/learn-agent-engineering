# Fundamentos de la ingeniería de prompts: cómo escribir instrucciones eficaces

Este curso te enseña a diseñar prompts claros y eficaces para que las herramientas de IA entiendan lo que necesitas y devuelvan respuestas de calidad. Al terminar sabrás construir prompts de forma sistemática, guiar a la IA con ejemplos, conseguir que muestre su razonamiento, depurar y mejorar tus instrucciones, y elegir la estrategia adecuada para cada tarea: generación de código, redacción, análisis de datos. Está pensado para perfiles de desarrollo y de trabajo del conocimiento que ya han usado herramientas como ChatGPT y Claude, pero quieren sacarles más partido.

**Al terminar este curso podrás:**
- Entender qué es un prompt y cuáles son sus elementos estructurales, detectar instrucciones vagas y reescribirlas con claridad
- Usar el few-shot learning para guiar a la IA hacia el patrón que buscas con 2-5 ejemplos
- Aplicar el chain-of-thought para que la IA muestre sus pasos de razonamiento y mejore su precisión en tareas complejas
- Depurar e iterar prompts de forma sistemática, identificando los problemas y mejorando paso a paso
- Elegir y aplicar la estrategia de prompt adecuada para la generación de código, la redacción, el análisis de datos y otros tipos de tarea

**Requisitos previos:** Has usado una herramienta de IA conversacional (ChatGPT, Claude y similares) y manejas la edición básica de texto y la descripción de una tarea.

**Entorno de práctica:** Necesitas acceso al menos a una herramienta de IA conversacional (ChatGPT, Claude, etc.). No hace falta ningún entorno de programación.
