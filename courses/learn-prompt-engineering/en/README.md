# Prompt Engineering Basics: How to Write Effective Instructions

This course teaches you how to design clear, effective prompts so AI tools understand what you need and return high-quality answers. By the end, you'll be able to build prompts systematically, guide AI with examples, get AI to show its reasoning, debug and improve your instructions, and pick the right strategy for different tasks — code generation, writing, data analysis. It's for developers and knowledge workers who have used tools like ChatGPT and Claude but want to get more out of them.

**By the end of this course you'll be able to:**
- Understand what a prompt is and its structural elements, spot vague instructions, and rewrite them clearly
- Use few-shot learning to guide AI toward the pattern you want with 2-5 examples
- Apply chain-of-thought to make AI show its reasoning steps and improve accuracy on complex tasks
- Debug and iterate on prompts systematically, identifying problems and improving step by step
- Choose and apply the right prompt strategy for code generation, writing, data analysis, and other task types

**Prerequisites:** You've used a conversational AI tool (ChatGPT, Claude, and the like) and understand basic text editing and describing a task.

**Practice environment:** You need access to at least one conversational AI tool (ChatGPT, Claude, etc.). No programming environment required.
