# Fundamentos de prompt engineering: como escrever instruções eficazes

Este curso ensina você a projetar prompts claros e eficazes para que as ferramentas de IA entendam o que você precisa e devolvam respostas de qualidade. Ao final, você será capaz de montar prompts de forma sistemática, guiar a IA com exemplos, fazer a IA mostrar seu raciocínio, depurar e melhorar suas instruções e escolher a estratégia certa para tarefas diferentes — geração de código, escrita, análise de dados. Ele é para quem desenvolve software e para profissionais do conhecimento que já usaram ferramentas como ChatGPT e Claude mas querem extrair mais delas.

**Ao final deste curso você será capaz de:**
- Entender o que é um prompt e quais são seus elementos estruturais, identificar instruções vagas e reescrevê-las com clareza
- Usar few-shot learning para guiar a IA até o padrão que você quer, com 2 a 5 exemplos
- Aplicar chain-of-thought para fazer a IA mostrar seus passos de raciocínio e melhorar a precisão em tarefas complexas
- Depurar e iterar prompts de forma sistemática, identificando problemas e melhorando passo a passo
- Escolher e aplicar a estratégia de prompt certa para geração de código, escrita, análise de dados e outros tipos de tarefa

**Pré-requisitos:** você já usou uma ferramenta de IA conversacional (ChatGPT, Claude e similares) e sabe editar texto e descrever uma tarefa.

**Ambiente de prática:** você precisa de acesso a pelo menos uma ferramenta de IA conversacional (ChatGPT, Claude etc.). Nenhum ambiente de programação é necessário.
