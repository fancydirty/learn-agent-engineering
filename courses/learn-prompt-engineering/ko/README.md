# 프롬프트 엔지니어링 기초: 효과적인 지시문 쓰는 법

이 코스에서는 AI 도구가 무엇을 원하는지 정확히 알아듣고 질 높은 답을 돌려주도록, 명확하고 효과적인 프롬프트를 설계하는 방법을 배웁니다. 코스를 마치면 프롬프트를 체계적으로 구성하고, 예시로 AI를 이끌고, AI가 추론 과정을 드러내게 하고, 지시문을 디버깅해 개선하고, 코드 생성·글쓰기·데이터 분석 같은 작업마다 알맞은 전략을 고를 수 있습니다. ChatGPT나 Claude 같은 도구를 써 봤지만 더 잘 활용하고 싶은 개발자와 지식 노동자를 위한 코스입니다.

**이 코스를 마치면 다음을 할 수 있습니다:**
- 프롬프트가 무엇이고 어떤 구조 요소로 이루어지는지 이해하고, 모호한 지시를 알아보고 명확하게 다시 쓰기
- few-shot 학습으로 2~5개의 예시를 써서 AI를 원하는 패턴으로 이끌기
- chain-of-thought를 적용해 AI가 추론 단계를 보여주게 하고 복잡한 작업의 정확도를 높이기
- 프롬프트를 체계적으로 디버깅하고 반복 개선하기 — 문제를 짚어내고 단계적으로 나아지게 하기
- 코드 생성, 글쓰기, 데이터 분석 등 작업 유형에 맞는 프롬프트 전략을 고르고 적용하기

**사전 지식:** 대화형 AI 도구(ChatGPT, Claude 등)를 써 본 적이 있고, 기본적인 텍스트 편집과 작업 설명을 할 수 있다.

**실습 환경:** 대화형 AI 도구(ChatGPT, Claude 등) 중 최소 하나에 접근할 수 있어야 합니다. 프로그래밍 환경은 필요하지 않습니다.
