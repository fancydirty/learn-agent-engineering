# 에이전트 워크플로 설계: 일회성 대화에서 다단계 자동화로

이 코스에서는 에이전트 워크플로를 설계하고 만드는 방법을 배웁니다. 복잡한 다단계 작업을 단일 대화 바깥으로 꺼내어, 오케스트레이션되고 복구 가능하며 확장되는 자동화 파이프라인으로 바꿉니다. Claude Code나 비슷한 AI 도구를 써 봤고 본격적인 자동화를 설계하고 싶은 개발자를 위한 코스입니다.

## 학습 목표

이 코스를 마치면 다음을 할 수 있습니다:
- 워크플로 오케스트레이션이 일회성 대화와 무엇이 다른지 이해하기
- 복잡한 작업을 실행 가능한 워크플로 단계로 체계적으로 분해하기
- 워크플로의 상태 관리와 체크포인트 설계하기
- 프로덕션에서 버티는 에러 처리와 복구 전략 만들기
- 프로덕션 수준의 멀티 에이전트 워크플로 조립하기

## 사전 지식

- Claude Code나 비슷한 AI 에이전트 도구를 써 본 적이 있다
- 기본적인 플로차트와 상태 머신을 이해한다
- JavaScript/TypeScript 코드를 읽을 수 있다
- 프로그래밍 언어를 하나라도 다뤄 본 경험이 있다

## 예상 학습 시간

실습 연습과 캡스톤 프로젝트를 포함해 약 4~5시간.
