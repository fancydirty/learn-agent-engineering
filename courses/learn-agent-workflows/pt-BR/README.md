# Projetando fluxos de trabalho de agentes: de conversas avulsas à automação de várias etapas

Este curso ensina você a projetar e construir fluxos de trabalho de agentes: levar tarefas complexas de várias etapas para além de uma única conversa, transformando-as em pipelines de automação orquestrados, recuperáveis e escaláveis. Ele é para quem já usou o Claude Code ou uma ferramenta de IA parecida e quer projetar automações sérias.

## Conteúdo do curso

1. [Da conversa ao fluxo de trabalho: por que a orquestração existe](01-from-conversation-to-workflow.md)
2. [Blocos de construção de um fluxo de trabalho: passos, estado, ramificações e loops](02-workflow-building-blocks.md)
3. [Decompondo uma tarefa complexa em um fluxo de trabalho](03-task-decomposition.md)
4. [Gerenciamento de estado e passagem de contexto](04-state-and-context.md)
5. [Tratamento de erros e estratégias de retentativa](05-error-handling-retry.md)
6. [Fluxos de trabalho do mundo real na prática](06-real-world-workflows.md)

## Objetivos de aprendizado

Ao final deste curso você será capaz de:
- Entender o que separa a orquestração de um fluxo de trabalho de uma conversa avulsa
- Decompor de forma sistemática uma tarefa complexa em passos executáveis de um fluxo de trabalho
- Projetar a gestão de estado e os checkpoints de um fluxo de trabalho
- Construir tratamento de erros e estratégias de recuperação que se sustentam em produção
- Montar fluxos de trabalho multiagente de nível de produção

## Pré-requisitos

- Você já usou o Claude Code ou uma ferramenta de agente de IA parecida
- Você entende fluxogramas e máquinas de estado básicos
- Você consegue ler código JavaScript/TypeScript
- Você tem experiência com alguma linguagem de programação

## Tempo estimado

Cerca de 4-5 horas, incluindo os exercícios práticos e o projeto final.
