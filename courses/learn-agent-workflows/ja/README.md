# エージェントワークフローの設計: 単発の会話からマルチステップ自動化へ

このコースでは、エージェントワークフローの設計と構築を学びます。複雑なマルチステップタスクを単一の会話を超えて、オーケストレーション可能で復旧可能でスケーラブルな自動化パイプラインへと進化させます。Claude Code や類似の AI ツールを使っていて、本格的な自動化を設計したい開発者向けです。

## コース構成

1. [会話からワークフローへ: オーケストレーションが存在する理由](01-from-conversation-to-workflow.md)
2. [ワークフローの構成要素: ステップ、状態、分岐、ループ](02-workflow-building-blocks.md)
3. [複雑なタスクをワークフローに分解する](03-task-decomposition.md)
4. [状態管理とコンテキストの受け渡し](04-state-and-context.md)
5. [エラーハンドリングとリトライ戦略](05-error-handling-retry.md)
6. [実践における実世界のワークフロー](06-real-world-workflows.md)

## 学習目標

このコースを終えると、次のことができるようになります:
- ワークフローオーケストレーションと単発の会話を区別する要素を理解する
- 複雑なタスクを実行可能なワークフローステップに体系的に分解する
- ワークフローの状態管理とチェックポイントを設計する
- 本番環境で機能するエラー処理と復旧戦略を構築する
- 本番レベルのマルチエージェントワークフローを組み立てる

## 前提知識

- Claude Code や類似の AI エージェントツールを使ったことがある
- 基本的なフローチャートや状態機械を理解している
- JavaScript/TypeScript のコードを読める
- いずれかのプログラミング言語の経験がある

## 想定学習時間

約 4〜5 時間（ハンズオン演習とキャップストーンプロジェクトを含む）。
