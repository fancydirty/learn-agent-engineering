# Agent 工作流设计：从单次对话到多步骤自动化

本课程教你如何设计和实现 Agent 工作流，将复杂的多步骤任务从单次对话扩展为可编排、可恢复、可扩展的自动化管道。适合已使用过 Claude Code 或类似 AI 工具、想要设计复杂自动化工作流的开发者。

## 课程大纲

1. [从单次对话到工作流：为什么需要编排](01-from-conversation-to-workflow.md)
2. [工作流的基本组成：步骤、状态、分支、循环](02-workflow-building-blocks.md)
3. [如何拆解复杂任务为工作流](03-task-decomposition.md)
4. [状态管理和上下文传递](04-state-and-context.md)
5. [错误处理和重试策略](05-error-handling-retry.md)
6. [真实场景工作流实战](06-real-world-workflows.md)

## 学习目标

完成本课程后，你将能够：
- 理解工作流编排与单次对话的本质区别
- 系统化地将复杂任务分解为可执行的工作流步骤
- 设计工作流的状态管理和检查点机制
- 实现健壮的错误处理和恢复策略
- 构建生产级的多代理协作工作流

## 前置要求

- 已经使用过 Claude Code 或类似 AI Agent 工具
- 理解基本的流程图和状态机概念
- 能够阅读 JavaScript/TypeScript 代码
- 有过任何编程语言的经验

## 预计学习时间

约 4-5 小时，包括动手练习和实战项目
