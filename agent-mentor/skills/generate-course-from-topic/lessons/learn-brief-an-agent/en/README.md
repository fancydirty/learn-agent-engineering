# Why Agents Build the Wrong Thing

This course is for people whose agent runs finish cleanly and produce something they did not want. It teaches you to find the decisions your request left blank, state a finish line the agent can check itself against, replace adjectives with examples, and name the small number of things the run must not touch — then run one real task with the rewritten brief. It covers how to state a requirement, not how to operate any particular tool, and it assumes no programming.

**By the end you'll be able to (course objectives):**
- Find the unstated decisions in one of your own requests before you send it.
- Predict which of those blanks an agent will fill silently rather than ask about.
- Write acceptance criteria someone else could check without your judgment.
- Replace an evaluative adjective with an example that carries the same requirement.
- Choose the two or three negative boundaries worth spending on, and say why each one exists.

**Prerequisites:** You have had an agent complete a task for you at least once, and you can open a text editor. No programming, no command line, and no experience writing specifications required.

**Practice environment:** Your own agent tool, your own files, and a scratch text file. This course has no embedded sandbox, runs nothing for you, and never asks you to upload anything.
