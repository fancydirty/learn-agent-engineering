# Your First Real Agent Task

This course is for people who already use AI chat and have never handed an agent a real, multi-step job and let it run. It teaches you to scope one real task in one of your own directories, watch what the agent actually does rather than what it says it did, and finish with a handoff record you could show someone else. It teaches mechanism and judgment, not the buttons of any particular product, and it assumes no programming.

**By the end you'll be able to (course objectives):**
- Tell whether a piece of work belongs in a chat turn or in a delegated run.
- Write a task boundary that names the finish line, the work area, and the actions the agent must ask you about first.
- Predict where an agent is most likely to stall or drift on your specific task, and size the task down until those risks are survivable.
- Read a run's action trail and find the gap between what happened and what the agent claims happened.
- Decide from observable signals whether to let a run continue, redirect it, or stop it and take over.

**Prerequisites:** You can use an AI chat tool, open a folder on your own computer, and read plain text. No programming, no command-line experience, and no prior agent runs required.

**Practice environment:** Your own computer, your own agent tool, and a scratch folder you choose. This course has no embedded sandbox, runs nothing for you, and never asks you to upload private files.
