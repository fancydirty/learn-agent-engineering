# Agent Skills：ワークフロー再利用入門

このコースは、Claude Code、Codex などの Agent をすでに使っているクリエイターや個人開発者に向けて、使い捨てプロンプトを、Agent が発見し、必要に応じて読み込み、再テストできる Skill として整える方法を教えます。公開されている Agent Skills ファイル仕様に沿って進めます。モデルのトレーニング、MCP サーバーの実装、プラグイン配布プラットフォーム、特定の業務領域の完全な方法論は扱いません。

**コースを修了すると、次のことができるようになります。**
- 使い捨てプロンプト、Skill、外部ツールの責務の境界を区別できます。
- 仕様に準拠し、トリガーされやすい `SKILL.md` のメタデータを書けます。
- `references/`、`assets/`、`scripts/` に資料と決定論的な操作をレイヤー分けして配置できます。
- Skill のトリガー、境界、出力品質のテストを設計し、失敗を記録できます。
- 自分のワークフローで、インストール可能で再テスト可能な Skill フォルダーを完成させられます。

**前提条件：** 何らかの coding agent を使え、ディレクトリの作成と Markdown ファイルの編集ができること。Python や JavaScript を書けること、API を呼び出せることは不要です。

**演習環境：** 自分の IDE、ターミナル、Agent を使います。このコースは組み込みの実行環境を提供せず、プライベートなファイルのアップロードも求めません。
